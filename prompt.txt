There is one semantic blocker:

# BLOCKER — `completedToday` is not actually “completed today”

Current implementation uses:

```ts
obs &&
obs.asOfDate === canonicalAsOfDate &&
(obs.status === 'completed' || obs.actualPercent >= 100)
```

This can incorrectly report an activity as completed today merely because its latest observation on the requested date still shows 100% / completed.

Example:

```text
Activity completed:
2026-08-20

Another observation:
2026-08-28
actualPercent = 100
status = completed
actualFinish = 2026-08-20
```

The current implementation would classify this as:

```text
completedToday on 2026-08-28
```

which is false.

## Required semantic rule

“Completed today” must mean that the activity's deterministic completion date is the requested `asOfDate`.

Use the canonical ActivityProgress fields already available in the repository.

Preferred rule:

```text
activity progress observation exists
AND
observation represents completion
AND
actualFinish === canonicalAsOfDate
```

Do not classify an activity as completed today merely because:

```text
observation.asOfDate === canonicalAsOfDate
```

when its actual completion date is earlier.

Also do not use:

```text
Evidence.uploadedAt
ProgressUpdate.createdAt
processing job completedAt
```

as activity completion dates.

ActivityProgress remains the source of truth.

# Edge cases

Test:

### Completion today

```text
actualFinish = 2026-08-28
asOfDate = 2026-08-28
status = completed
actualPercent = 100
```

→ MUST appear in `completedToday`.

### Completed earlier, observed today

```text
actualFinish = 2026-08-20
asOfDate = 2026-08-28
status = completed
actualPercent = 100
```

→ MUST NOT appear in `completedToday`.

### No actualFinish but 100%

Do NOT invent a completion date.

Define and document the fallback behavior explicitly.

Prefer excluding it from `completedToday` unless the existing canonical progress semantics establish another deterministic completion-date signal.

### Historical query

For:

```text
asOfDate = 2026-08-20
```

an activity with:

```text
actualFinish = 2026-08-20
```

must appear.

An activity with:

```text
actualFinish = 2026-08-21
```

must not appear because that completion was in the future relative to the snapshot.

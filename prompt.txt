# Architectural direction

FieldLine will be a **single local modular monolith**.

The intended high-level shape is:

```text
FieldLine/
├── backend/
├── frontend/
├── database/
├── uploads/
├── demo/
├── scripts/
├── docs/
├── package.json
├── tsconfig.json
├── .env.example
├── .gitignore
└── README.md
```

The exact structure may be adjusted based on what you discover during implementation, but preserve the intended architectural boundaries.

The later backend architecture will follow this general direction:

```text
HTTP route
    ↓
validation
    ↓
service
    ↓
repository
    ↓
SQLite
```

and later the AI layer will follow:

```text
AI service
    ↓
AI adapter
    ↓
structured response
    ↓
validation
    ↓
service
```

AI code must not directly manipulate the database.

Pass 0 does **not** need to implement these feature layers fully. It only needs to create a clean foundation that can support them.

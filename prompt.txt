CORE VISUAL DIRECTION

The principle is:

"Remove persistent decorative boxes. Keep boundaries only where they communicate a real interaction, containment, danger state, modal state, form control, table structure, or technical content."

I do NOT want a blanket:
border: none;
everywhere.

I want the interface hierarchy to be created primarily through:
- spacing
- typography
- alignment
- subtle background tonal changes
- section dividers
- accent color
- whitespace
- hover/active states

The resting UI should feel calm and information-dense rather than card-heavy.

BUTTONS

This is especially important.

Clickable buttons should generally NOT look like permanent boxes.

Default/resting state:
- transparent background
- no visible border
- no permanent box shadow
- icon + text should carry the control
- color should communicate importance

Hover/focus interaction:
- show a subtle ghost boundary around the control
- ghost boundary should be in an appropriate accent color
- use a method that does not cause layout shift
- an existing transparent border or equivalent outline/box-shadow is preferable to changing border width on hover

Examples:
- normal/navigation/action button -> subtle neutral ghost boundary
- primary action -> blue/indigo/cyan accent ghost boundary as appropriate
- success action -> emerald
- warning -> amber
- destructive/cancel/delete/reject -> rose/red

The box should appear because the user is interacting with the control, not because the control permanently exists inside a card.

Please standardize this behavior through the existing CSS system rather than inventing dozens of unrelated one-off hover styles.

IMPORTANT IMPLEMENTATION DETAIL

Avoid layout shift on hover.

Do not implement:

in a way that changes element dimensions.

Prefer:
- transparent 1px border already occupying space
OR
- outline
OR
- box-shadow as the interaction ring

with subtle opacity.

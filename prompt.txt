We have a production PostgreSQL failure on Render:

```text
DatabaseError: Failed to claim next eligible notification:
column "updated_at" is of type timestamp with time zone
but expression is of type text
```

The error occurs in:

```text
backend/src/repositories/postgres/postgres-notification-outbox.repository.ts
```

inside `claimNextEligible()`.

I have already investigated the current `main` branch and there is a strong indication that this is a PostgreSQL schema/repository timestamp-type mismatch rather than a transient database problem.
